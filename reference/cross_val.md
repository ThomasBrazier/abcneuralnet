# Cross-validation metrics between ground truth and predictions

The function computes cross-validation metrics between ground truth and
predictions

## Usage

``` r
cross_val(cross_validation_param, cross_validation_predictions)
```

## Arguments

- cross_validation_param:

  a tidy data frame with ground truth simulated parameters

- cross_validation_predictions:

  a tidy data frame with predictions

## Value

a data frame with cross-validation metrics
